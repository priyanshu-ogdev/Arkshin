# Literature Survey & Prior Work Taxonomy (`research/survey`)

## Purpose
Houses literature review notes, bibliography databases (BibTeX), comparative taxonomy matrices,
and synthesis documents surveying prior work across academic research libraries.

## Publisher & Literature Scope
- **IEEE Xplore**: Agentic security, automated pentesting frameworks, prompt-injection mitigations, and formal policy enforcement.
- **ScienceDirect / Computers & Security**: MicroVM sandboxing, CTI ontology representations, and automated vulnerability triage.
- **Scopus**: Bibliometric tracking and lineage analysis for proper-scoring-rule RL (RLCD, RLCR, "Rewarding Doubt") and Conformal Prediction.
- **SpringerLink (LNCS / ESORICS / ICICS)**: Formal methods in access control, verified authorization models, and secure software execution.

## Files
- `literature_review.md`: Detailed synthesis of prior work, comparative matrices, and baseline gaps.
- `references.bib`: Master BibTeX bibliography file.
- `taxonomy_matrix.md`: Side-by-side feature comparison between Arkshin and prior systems (RedSage, SecGemini, Foundation-Sec, DeepHat, HackSynth, ARACNE).
