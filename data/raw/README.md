# Raw Data Staging (`data/raw`)

## Purpose
Staging directory for authentic, uncompressed open-source and public datasets downloaded from upstream repositories.
All raw data files in this folder are excluded from Git commits via `.gitignore`.

## Ingested Datasets
- **Primus-Seed**: Expert-curated CTI and 6,499 cybersecurity books.
- **Primus-Instruct**: Authentic analyst task-solution pairs.
- **NL2Bash**: ~10K natural language to bash command pairs.
- **Corrected InterCode-Bash**: 600 execution-validated instruction-command pairs.
- **InterCode-CTF**: PicoCTF task objectives and Docker environments.
- **CTF-Dojo**: 486 execution-verified containerized challenge trajectories.
