# Cybersecurity Taxonomies & Ontologies (`data/taxonomies`)

## Purpose
Canonical mappings and structured taxonomic data from official cybersecurity standards bodies.
Used for building Tier 1/2 Knowledge stores and pairing authentic NLI premise-hypothesis verification examples.

## Tracked Taxonomies
- **NVD / CVE**: Common Vulnerabilities and Exposures JSON schema 5.0 feeds and CVSS vector definitions.
- **CISA KEV**: Known Exploited Vulnerabilities catalog (authoritative remediation actions).
- **MITRE ATT&CK**: Enterprise matrix techniques, sub-techniques, and threat actor profiles (STIX 2.1).
- **MITRE D3FEND**: Defensive countermeasure ontology and matrix mappings.
- **MITRE CWE / CAPEC**: Common Weakness Enumeration and Common Attack Pattern Enumeration and Classification.
